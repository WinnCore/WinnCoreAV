# av-attack-sim

Fast attack simulation utility used to generate realistic process activity for validation, demos, and regression testing. It is intended for local validation and CI simulation runs.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-attack-sim --bin attack-sim
```
