# av-cli

Command-line interface for scanning files and managing quarantine in WinnCoreAV. Provides a simple CLI wrapper around `av-core`, `av-signatures`, and `av-quarantine`.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-cli -- scan /path/to/file
```
