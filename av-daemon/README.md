# av-daemon

System daemon for WinnCoreAV real-time monitoring and response orchestration. This crate is primarily intended to run as a service and wires together scanners, behavioral monitoring, and response actions.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-daemon
```
