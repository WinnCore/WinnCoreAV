# av-ebpf-detect

eBPF-oriented rootkit indicator checks for WinnCoreAV. Focuses on kernel tampering and module-level anomalies.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```rust
use av_ebpf_detect as _;
```
