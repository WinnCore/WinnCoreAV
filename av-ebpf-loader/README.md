# av-ebpf-loader

Userspace loader for WinnCoreAV eBPF probes. Intended to pin/load eBPF programs and support structured event streaming.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-ebpf-loader
```
