# av-ebpf-probes

eBPF probe programs for WinnCoreAV behavioral telemetry on Linux.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

This crate targets `bpfel-unknown-none` and is not intended for standalone use or crates.io publishing.
