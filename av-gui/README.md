# av-gui

Desktop interface for WinnCoreAV. This crate contains the Tauri-based GUI and supporting library code (built with the `gui` feature).

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-gui --features gui --bin av-gui
```
