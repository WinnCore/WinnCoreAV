# av-mitre-tests

MITRE ATT&CK test suite utilities for WinnCoreAV validation. Contains helpers and a runner binary to execute ATT&CK-mapped tests locally.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-mitre-tests --bin mitre-test-runner
```
