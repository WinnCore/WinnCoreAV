# av-watchdog

Systemd watchdog and health-check helper for WinnCoreAV services. Intended to run alongside the daemon to report READY/STATUS and watchdog keepalives.

Part of [WinnCoreAV](https://github.com/WinnCore/WinnCoreAV) - ARM64-native endpoint detection for Linux.

## Usage

```bash
cargo run -p av-watchdog
```
